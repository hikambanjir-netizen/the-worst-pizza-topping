One line pitching the worst pizza topping ever invented, written for the
[make.fun](https://make.fun/bounty/u-motasimfuad-the-worst-pizza-topping-062c6893)
bounty **"The Worst Pizza Topping"**.

> Anchovy-flavoured gummy bears, melted on at 450 degrees, so every slice tastes like a beach at low tide.

`main.py` writes that single line (104 characters) to `/output/entry.txt`,
pure Python standard library, no third-party packages. It self-checks the gate
before writing: UTF-8 text, 1 to 199 characters, a single non-blank line.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
